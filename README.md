# BAP Performance Lab v0.2 — Validação

Protótipo estático multipágina de validação visual e editorial, não publicado. Abra `index.html` ou sirva a pasta com `python -m http.server 8000`.

## Páginas
Home, O Método, Curso, Vídeos, Livro, Sobre o autor, Blog, Loja, Contato.

## Importante
- Marca `assets/logo-bap-original.jpg` fornecida pelo cliente e mantida sem alterações.
- Fotografias `hero.jpg`, `corpo.jpg`, `course.jpg`, `tiago-conceitual.jpg` são recortes da referência visual aprovada, *não* fotografias reais confirmadas de Tiago. Substituir por materiais oficiais licenciados antes de publicar.
- Links de checkout Hotmart e Freenote preservados. Blog, vídeo, livro, loja e autor remetem às URLs originais quando os conteúdos não estão migrados.
- Antes de configurar o domínio, executar inventário integral de hyperlinks e redirecionamentos permanentes para URLs antigas; especialmente as rotas Wix e formulários.
- Não há backend, pagamentos locais ou upload de vídeo.
