# BAP Icons Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Aplicar a família de ícones aprovada em todo o site e à dobra Primeiros Ritmos apresentada.

**Architecture:** Sprite SVG compartilhado por referências estáticas. CSS de integração carregado após os estilos existentes. Ajuste mínimo do menu dinâmico e dos ícones nas respostas do diagnóstico.

**Tech Stack:** HTML, CSS, SVG e JavaScript existentes; sem dependências.

**Spec:** ../specs/2026-11-18-bap-icons-design.md

## Global Constraints

- Uma única cor por ícone, herdada do contexto.
- Preservar paleta, fontes, imagens, destinos e comportamento dos controles.
- Redes sociais mantêm marcas oficiais; Livro mantém artes rasterizadas.

## Review Focus

- Pseudoícones CSS não podem aparecer junto do SVG novo.
- Menu deve manter ícone e nome acessível depois de abrir, fechar e pressionar Escape.
- Reiniciar diagnóstico deve restaurar os ícones dos perfis.
- Referências SVG devem resolver em todas as páginas, sem alterar áreas de clique.
- Dobra Primeiros Ritmos deve caber em 320px e manter rostos visíveis.
